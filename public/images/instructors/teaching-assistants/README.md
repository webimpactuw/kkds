# Teaching assistant portraits

Drop one photo per assistant in this folder using **exactly** these filenames.
Supported formats: `.jpg`, `.jpeg`, or `.png` (update the extension in
`lib/data/content/v1.ts` if you use `.png`).

| Filename | Dancer |
|---|---|
| `anika-yechuri.jpg` | Anika Yechuri |
| `eesha-koduru.jpg` | Eesha Koduru |
| `haritha-gali.jpg` | Haritha Gali |
| `lakshmi-gali.jpg` | Lakshmi Gali |
| `manyada-alapaty.jpg` | Manyada Alapaty |
| `nithika-yechuri.jpg` | Nithika Yechuri |
| `nitya-masina.jpg` | Nitya Masina |
| `pournami-varma.jpg` | Pournami Varma |
| `sneha-pilli.jpg` | Sneha Pilli |
| `vipra-manchi.jpg` | Vipra Manchi |

After adding images, re-run `npm run seed` to upload them to Sanity (or upload
directly in Studio at `/studio`).

Until photos are added, the site shows a branded placeholder for missing images.
